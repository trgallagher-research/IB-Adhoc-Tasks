# Paste-ready Compose actions

Each file is a Power Automate clipboard-format action. To use: open the file, select ALL its JSON, copy, then in the flow editor add a step via **My clipboard** (classic designer: + New step -> My clipboard tab -> Ctrl+V; new designer: copy any action first so 'Paste an action' appears on the + menu, then Ctrl+V-paste this JSON). After pasting, verify with Peek code: `inputs` must be an OBJECT for the payload compose (values starting with a single `@`) and a text template for the labelled submission (interpolations as `@{...}`). If Peek code shows `@@`, the designer escaped the paste — delete the action and use the clipboard route, not the input field.

Regenerated by `scripts/generate_artifacts.py`; do not hand-edit.
